# 🎶 Flute Mastery Journey

An interactive, animated guide to the **Indian classical bansuri** — daily riyaaz, finger-hole charts, ragas, taal and technique, from beginner to professional.

**Live site:** https://xudipta.github.io/Flute-Mastery-Journey/

## Features
- App-style navigation: five tabs (Home, Practice, Alankar, Ragas, Learn) in a bottom tab bar on phones and a top bar on desktop. The tanpura, tabla and timer keep playing when you change tab, and Back/Forward and links such as `#practice` or `#tuner` work
- Alankar tab: 18 practice patterns (straight run, groups of three to five, skips, criss-cross, arches ...) in 10 scales (Shuddha, Kalyan, Kafi, Asavari, Khamaj, Bhairav and four pentatonic ragas), played ascending then descending on the Sa you chose. Play them with the tanpura and a tabla taal (or a click), at 1, 2 or 4 notes a beat, with a tempo slider, a speed trainer that raises the tempo every few rounds, the finger chart lighting up note by note, and a Stop bar that stays on screen
- Daily riyaaz routine with per-block timers (a running block survives a reload and shows in the tools bar), a breathing animation and a streak tracker (saved in your browser)
- Keeps the screen on while a timer, the tanpura or the tabla is running, and keeps the sound and the end-of-block bell steady when the phone locks or another app is in front
- "Today" card for returning visitors, a first-run Sa picker, and a raga finder (search, time of day, starter ragas, favourites, one-tap aroha preview)
- Pitch tuner: pauses the tanpura and tabla while it listens through the microphone, shows the swar and cents sharp/flat against your Sa, with a pitch trace and a steadiness score (analysed on the device)
- Synthesised tanpura and tabla, controlled from a tools bar that stays on screen. The tanpura is tuned exactly (each string is built from exact harmonics), has a jivari shimmer, a choice of first string (Pa, Ma or Ni), pluck speed and a fine tune, and a Sa range that goes down to a low G; it is built in the background, so changing the scale never freezes the page
- Tabla taal player (Teentaal, Dadra, Keherwa, Jhaptaal, Ektaal, Rupak) with adjustable tempo
- Tap-to-hear six-hole finger chart across three octaves (komal/tivra and note-name options, play the scale), with half-covered holes
- Animated "How to play" demos for 16 ragas (aroha, avaroha, pakad on a finger-hole diagram with sound)
- "Show me how" animated demos for each daily practice block (breathing, long tones, alankars, alaap, taan & taal, cool-down)
- Your progress: practice calendar with day notes, streaks, and backup/restore (export and import)
- Editable routine: presets (15, 30, 55 min), on/off, minutes and order
- Five-stage roadmap, 23 raga cards filterable by time of day, and bansuri technique cards (meend, kan, taan, tonguing)

## Install and offline
The site is an installable web app (manifest + service worker). After the first visit it works offline, and
browsers that support it show an "Install as an app" link in the footer. The service worker is network-first,
so a new deploy appears as soon as you are online; bump `VERSION` in `sw.js` to clear old caches.

Icons and the social preview image are generated by `node tools/make-icons.js` (needs `playwright`).
`node tools/check-tanpura.js` measures the tanpura without a browser: pitch error of every string for all Sa at 44.1 and 48 kHz (it exits with an error if any string is more than 1 cent off), build time, and how loud and bright a string stays over time.

## Run locally
It is a plain static site (no build step):

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

## Deployment
GitHub Pages deploys via `.github/workflows/pages.yml` on every push to `dev`.
In the repository go to **Settings → Pages → Source: GitHub Actions** (one-time).

## Structure
```
index.html          page markup
assets/styles.css   styling (light/dark aware)
assets/app.js       routine, timer, tools bar, finger chart, content data
assets/nav.js       tab router: one view at a time (window.FluteNav: go, current, onShow, onHide)
assets/home.js, home.css, practice-cards.js, practice-cards.css, alankar.js, alankar.css
                    one script and stylesheet per view (Home, Practice, Alankar), loaded after the others
assets/audio.js     tabla, tanpura, bell and flute-line synthesis, audio engine
assets/transport.js shared beat grid: tabla and melody on one clock, gapless loops (see header for the API)
assets/demo.js      finger chart, swar fingering model, demo dialog and player
assets/ragas.js     raga notation data
assets/alankar-data.js  alankar patterns and scales (add a line to add one; `node tools/check-alankar.js` checks them all)
assets/tuner.js     microphone pitch tuner (YIN detector)
assets/progress.js  calendar, day notes, routine editor, backup/restore
assets/practice-demos.js  demos for the daily practice blocks
assets/favicon.svg
```

The page is five views, each `<section class="view" id="view-NAME" data-view="NAME">`: `home` (Today card and
tabla taal player), `practice` (routine, timer, progress calendar), `alankar`, `ragas`, `learn` (tuner, finger-hole
chart, roadmap, techniques). Add a view by adding its section, a tab link `<a href="#NAME" data-view="NAME">` in
both navs, and its name to `VIEWS` in `assets/nav.js`.
