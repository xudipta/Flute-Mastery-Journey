# 🎶 Flute Mastery Journey

An interactive, animated guide to the **Indian classical bansuri** — daily riyaaz, finger-hole charts, ragas, taal and technique, from beginner to professional.

**Live site:** https://xudipta.github.io/Flute-Mastery-Journey/

## Features
- A paper-and-ink look in light and dark mode with one terracotta accent, a serif for titles and the system sans for everything else: one set of design tokens, flat surfaces with 1 px lines (no gradients, glows or coloured shadows), one set of monoline SVG icons, round play buttons, bottom sheets for choices, and safe-area padding on notched phones. Contrast is checked in `tools/check-contrast.js`
- App-style navigation: five tabs (Home, Practice, Alankar, Ragas, Learn) in a bottom tab bar on phones and a top bar on desktop. The tanpura, tabla and timer keep playing when you change tab, and Back/Forward and links such as `#practice` or `#tuner` work
- Alankar tab: 18 practice patterns (straight run, groups of three to five, skips, criss-cross, arches ...) in 10 scales (Shuddha, Kalyan, Kafi, Asavari, Khamaj, Bhairav and four pentatonic ragas), played ascending then descending on the Sa you chose. Play them with the tanpura and a tabla taal (or a click), at 1, 2 or 4 notes a beat, with a tempo slider, a speed trainer that raises the tempo every few rounds, the finger chart lighting up note by note, and a Stop bar that stays on screen
- Daily riyaaz as swipeable cards, one per practice block, each with its own large timer (a running block keeps running when you swipe away, survives a reload and shows in the now-playing bar), plus a streak tracker (saved in your browser)
- Keeps the screen on while a timer, the tanpura or the tabla is running, and keeps the sound and the end-of-block bell steady when the phone locks or another app is in front
- Home is a Tanpura and Taal player on one screen: the scale (Sa) is the big letter, with ◀ ▶ semitone steps and a sheet of all scales; "Hear Sa" lets you check the tanpura against a clean note. The tanpura and the taal sit in one panel (play buttons, volume, tempo −/+ and the beat grid with sam ✕, tali numbers and khali ○), and two sheets hold the taal list with a tempo slider and tap tempo, and the tuning options (first string, pluck speed, fine tune, volumes). The Today card and your streak sit at the top of Practice
- A slim now-playing bar above the tab bar shows what is sounding (tanpura, taal) and what is counting down (a block timer) on every tab but Home, with a button that stops the sound
- Ragas: one list of 23 ragas with a time-of-day tile, search, a time-of-day filter row, Starter and Favourites toggles, a one-tap aroha preview on each row, and a header button for the ragas of the current time of day
- Pitch tuner: pauses the tanpura and tabla while it listens through the microphone, shows the swar and cents sharp/flat against your Sa, with a pitch trace and a steadiness score (analysed on the device)
- Synthesised tanpura and tabla, controlled from Home (and stopped from the now-playing bar on other tabs). The tanpura is tuned exactly (each string is built from exact harmonics), has a jivari shimmer, a choice of first string (Pa, Ma or Ni), pluck speed and a fine tune, and a Sa range that goes down to a low G; it is built in the background, so changing the scale never freezes the page
- Tabla taal player (Teentaal, Dadra, Keherwa, Jhaptaal, Ektaal, Rupak) with adjustable tempo
- Tap-to-hear six-hole finger chart across three octaves (komal/tivra and note-name options, play the scale), with half-covered holes
- A raga's row opens a bottom sheet with its mood, vadi/samvadi/thaat, and (for 16 ragas) an animated "How to play" demo: aroha, avaroha and pakad on a finger-hole diagram with sound, speed and loop
- "Show me how" animated demos for each daily practice block (breathing, long tones, alankars, alaap, taan & taal, cool-down)
- Your progress: practice calendar with day notes, streaks, and backup/restore (export and import)
- Editable routine: presets (15, 30, 55 min), on/off, minutes and order
- Learn tab: the tuner, the finger-hole guide, a five-stage roadmap as a timeline, and eight core bansuri techniques (meend, kan, taan, tonguing ...)

## Install and offline
The site is an installable web app (manifest + service worker). After the first visit it works offline, and
browsers that support it show an "Install as an app" link in the footer. The service worker is network-first,
so a new deploy appears as soon as you are online; bump `VERSION` in `sw.js` to clear old caches.

Icons and the social preview image are generated by `node tools/make-icons.js` (needs `playwright`).
`node tools/check-contrast.js` checks the WCAG contrast of the colour tokens in dark and light mode (text 4.5:1, borders and focus rings 3:1), and `node tools/check-css-unused.js` lists CSS class and id names that no HTML or JS mentions.
`node tools/check-tanpura.js` measures the tanpura without a browser: pitch error of every string for all Sa at 44.1 and 48 kHz (it exits with an error if any string is more than 1 cent off), build time, and how loud and bright a string stays over time.

## Run locally
It is a plain static site (no build step):

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

### Tests
The checks need Node and `playwright` (`npm i playwright`). Node checks (no browser):

```sh
node tools/check-tanpura.js     # pitch of every tanpura string, level and brightness
node tools/check-transport.js   # tabla and melody share one beat grid
node tools/check-alankar.js     # alankar pattern data
node tools/check-contrast.js    # WCAG contrast of the colour tokens, light and dark
node tools/check-css-unused.js  # no unused class or id names in the stylesheets
```

Browser suites (tabs, Home, practice cards, timer, wake lock, polish), against the running site:

```sh
python3 -m http.server 8800                       # in one terminal
BASE=http://localhost:8800 node tools/browser/run-all.js [--long] [screenshot-folder]
```

`--long` also runs `tools/check-alankar-browser.js` (about 100 s of real audio time). Each suite can be run
alone, for example `BASE=http://localhost:8800 node tools/browser/nav.js`. The controls the suites touch are listed in
`tools/browser/lib.js`, so a UI change only needs that file updated.

## Deployment
GitHub Pages deploys via `.github/workflows/pages.yml` on every push to `dev`.
In the repository go to **Settings → Pages → Source: GitHub Actions** (one-time).

## Structure
```
index.html          page markup
assets/styles.css   design system: tokens (light/dark), base, icons, form controls, cards, app shell, shared content, and the shared components (v2) the views build on (see its header)
assets/ui.js        shared UI helpers (window.FluteUI): icons, button labels, bottom sheets, slider fill
assets/app.js       routine, timer, audio state (scale, tanpura, taal, tempo) with window.FluteApp, finger chart, content data
assets/mini.js      the now-playing bar
assets/nav.js       tab router: one view at a time (window.FluteNav: go, current, onShow, onHide)
assets/home.js, home.css, practice-cards.js, practice-cards.css, alankar.js, alankar.css
                    one script and stylesheet per view (Home, Practice, Alankar), loaded after the others
assets/audio.js     tabla, tanpura, bell and flute-line synthesis, audio engine
assets/transport.js shared beat grid: tabla and melody on one clock, gapless loops (see header for the API)
assets/demo.js      finger chart, swar fingering model, demo dialog and player
assets/ragas.js     raga notation data
assets/ragas.css, learn.css  styles of the Ragas tab (list, filters, demo sheet) and the Learn tab (tuner, finger chart, roadmap, techniques)
assets/alankar-data.js  alankar patterns and scales (add a line to add one; `node tools/check-alankar.js` checks them all)
assets/tuner.js     microphone pitch tuner (YIN detector)
assets/progress.js  calendar, day notes, routine editor, backup/restore
assets/practice-demos.js  demos for the daily practice blocks
assets/favicon.svg
```

The page is five views, each `<section class="view" id="view-NAME" data-view="NAME">`: `home` (tanpura and
taal player), `practice` (Today card, routine, timer, progress calendar), `alankar`, `ragas`, `learn` (tuner, finger-hole
chart, roadmap, techniques). Add a view by adding its section, a tab link `<a href="#NAME" data-view="NAME">` in
both navs, and its name to `VIEWS` in `assets/nav.js`.
